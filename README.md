## Setup and run for developers

### Prerequisites
- **Git**: [Install Git](https://git-scm.com/downloads) for cloning repositories.
- **Node**: [Install Node](https://nodejs.org/en/download) for creating and installing the project.

### Steps

```bash
# Clone repository
git clone <repository-url>
cd <repository-folder>

# Install project
npm install

# Run development environment
npm run dev
```
